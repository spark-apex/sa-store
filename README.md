## ✨ 简介

SA-Store 是 SA-Products 生态的核心基础设施，为所有产品提供统一的版本发布、更新检查和下载服务。同时支持第三方开发者上架应用。

## 🚀 核心功能

| 功能 | 描述 |
|------|------|
| **更新检查** | 兼容 Tauri updater 标准格式，所有产品客户端自动对接 |
| **版本管理** | 多版本、多平台支持，完整版本历史 |
| **应用注册** | SA 官方应用 + 第三方开发者应用 |
| **审核机制** | 官方应用自动通过，第三方需管理员审核 |
| **下载统计** | 记录每次下载，提供数据分析 |

## 🛠️ 技术栈

| 层 | 技术 |
|---|------|
| **API** | Rust + Axum 0.8 |
| **数据库** | PostgreSQL 18 |
| **容器** | Docker Compose |

## 📦 快速开始

```bash
# 1. 启动数据库
docker compose up -d postgres

# 2. 启动后端
cd backend && cargo run
```
